# مؤشرات لقاءات – لوحة معلومات تفاعلية

لوحة عرض تفاعلية (1920×1080، 16:9، RTL) لاستعراض مؤشرات «لقاءات» في المناطق الإدارية الـ13 بالمملكة العربية السعودية.

## التشغيل
افتح `index.html` مباشرةً في Chrome أو Edge (لا يحتاج خادمًا ولا إنترنت).
- زر ملء الشاشة أعلى يسار الشاشة، أو اضغط `F`.
- الأسهم ← / → تنتقل بين المناطق (مفيد مع جهاز التحكم بالعرض).
- التصميم مبني على مسرح ثابت 1920×1080 يُكبَّر/يُصغَّر تلقائيًا ليناسب أي شاشة مع الحفاظ على النسب.

## التصدير (Export)
```
python3 tools/export.py
```
ينتج في `dist/`:
- `liqaat-dashboard.html` — ملف واحد مستقل (الأكواد والبيانات والخطوط والصور مدمجة) يُفتح على أي جهاز دون إنترنت.
- `liqaat-dashboard.zip` — نسخة المشروع القابلة للتعديل.

أعد تشغيل الأمر بعد أي تعديل على البيانات أو التصميم.

## هيكل المشروع
```
index.html                 بنية الصفحة
css/style.css              التصميم (الألوان في :root)
css/fonts.css              الخطوط
js/app.js                  الخريطة والتفاعل وتحديث اللوحة
js/icons.js                الأيقونات (Lucide – ISC)
js/background.js           أضواء الخلفية
data/regions.js            ⬅ بيانات المناطق (عدّل هنا)
data/map-data.js           مسارات الخريطة (مولّدة – لا تُعدَّل يدويًا)
data/source/               ملف GeoJSON الأصلي للحدود
tools/build-map.py         يولّد data/map-data.js من GeoJSON
assets/img, assets/fonts   الصور والخطوط
```

## تعديل البيانات
كل البيانات في `data/regions.js` (بنية JSON داخل ملف JS ليعمل الملف من القرص دون خادم):
- الأرقام الأربعة: `visitors`, `guidanceSessions`, `workshops`, `jobOpportunities`.
- `sectors`: أسماء القطاعات (حتى 5). الأيقونة تُختار من `sectorIcons`؛ قطاع جديد يأخذ أيقونة افتراضية.
- `venues`: `[{ name, image }]` (حتى 4). المصفوفة الفارغة تُظهر «لا توجد مواقع مضافة لهذه المنطقة».
- `headerImage`: صورة بانورامية خلف عنوان اللوحة (اختياري).
- ترتيب المفاتيح = ترتيب أزرار الشريط السفلي.

> ⚠️ **جميع الأرقام الحالية تجريبية وليست إحصائيات رسمية.** يظهر تنبيه «بيانات تجريبية» في اللوحة ما دام `meta.isDemo = true`؛ غيّره إلى `false` بعد إدخال البيانات المعتمدة.

## الخريطة والدقة الجغرافية
- الحدود من **geoBoundaries (gbOpen, SAU ADM1)** المشتقة من **OpenStreetMap** (© OpenStreetMap contributors، رخصة ODbL 1.0)، بإسقاط متساوي المسافات عند خط عرض 24° شمالًا. الخريطة لا تنعكس في وضع RTL.
- **تصحيح مُطبَّق:** المصدر (وكذلك Natural Earth) ينسب ساحل عسير على البحر الأحمر (محافظتا البرك والقحمة، نحو 140 كم) إلى مكة المكرمة وجازان. يقوم `tools/build-map.py` بنقل هذا الشريط إلى منطقة عسير. الحدود الشمالية/الجنوبية لهذا الشريط تقريبية (خطوط عرض 18.65° و17.93°)، ويُفضّل اعتماد ملف حدود رسمي من الهيئة العامة للمساحة عند توفره.
- لإعادة التوليد: `pip install shapely && python3 tools/build-map.py`. مواضع أسماء المناطق تُحسب تلقائيًا ويمكن ضبطها عبر `LABEL_NUDGE`.
- أسماء المناطق في الخريطة مصححة (الصورة المرجعية تكرّر «الباحة» وتضع جازان في غير موضعها).

## الأصول البصرية – مهم قبل الاعتماد النهائي
- **الشعار** `assets/img/logo-liqaat.png` و**صور الأفق والمواقع** في `assets/img/` مقتطعة من الصورة المرجعية (`tools/extract-reference-assets.py`) لأن الملفات الأصلية لم تُرفق. دقتها محدودة؛ استبدلها بالملفات الأصلية بنفس الأسماء للحصول على أفضل وضوح على الشاشة الكبيرة.
- صور مواقع الرياض أمثلة بصرية مؤقتة وليست مواقع مؤكدة لإقامة لقاءات.
- **الخط:** يُستخدم SST Arabic تلقائيًا إن كان مثبتًا على الجهاز، وإلا IBM Plex Sans Arabic المضمّن (SIL OFL). لإضافة SST Arabic كخط ويب مرخّص أضف `@font-face` في `css/fonts.css` باسم `"SST Arabic"`.
